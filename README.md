Avances del proyecto - Safe Notes

Frontend en React (Semana 4)
- Consumo de la API REST de Spring Boot (`/api/notas`) mediante `fetch`, `useState` y `useEffect`.
- Estructura modular con componentes `App`, `ListaNotas` y `TarjetaNota` comunicados por `props`.
- Formulario controlado para crear y guardar nuevas notas con `texto`, `categoria` e `importante` (`POST`).
- Búsqueda en tiempo real, filtro de notas importantes y eliminación de registros (`DELETE`).
- Interfaz de dos columnas en tema oscuro y video demostrativo del funcionamiento integrado.
